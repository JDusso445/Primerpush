# Primerpush - Análisis de Abandono de Clientes

## 📋 Descripción
Este proyecto analiza datos de clientes para predecir el abandono.

## 🚀 Proyecto Piloto en Data Science
Creamos una App para prevenir el abandono de clientes mediante análisis predictivo y machine learning.

## 🎯 Objetivos
- Analizar patrones de abandono de clientes
- Crear modelos predictivos de churn
- Desarrollar una aplicación para prevenir la pérdida de clientes
- Visualizar insights clave de los datos

## 💻 Tecnologías
- **Python** - Lenguaje principal
- **Pandas** - Manipulación de datos
- **Scikit-learn** - Machine Learning
- **Matplotlib/Seaborn** - Visualización
- **Jupyter Notebook** - Análisis exploratorio

## 📁 Estructura del Proyecto
```text
Primerpush/
├── data/              # Datos crudos y procesados
├── notebooks/         # Análisis exploratorio (EDA)
├── models/            # Modelos entrenados
├── app/               # Aplicación principal
├── requirements.txt   # Dependencias
├── README.md          # Este archivo
└── .gitignore
```

## 🔧 Instalación
```bash
# Clonar el repositorio
git clone https://github.com/JDusso445/Primerpush.git
cd Primerpush

# Instalar dependencias
pip install -r requirements.txt
```

## 📊 Uso
```bash
# Ejecutar el análisis
jupyter notebook notebooks/

# Ejecutar la aplicación
python app/main.py
```
